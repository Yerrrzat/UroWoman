# Анкета и статистика в Excel

На странице теста есть необязательный блок «Участие в исследовании». Если посетительница отмечает согласие, она указывает возраст, образование, занятость и семейное положение, а после расчёта результата её ответы анонимно попадают в Google Таблицу. Таблицу можно в любой момент скачать как файл Excel.

Без согласия тест работает как раньше и ничего не отправляет.

## Что попадает в таблицу

Одна строка на одну анкету:

| Столбец | Значение |
|---|---|
| Дата и время | когда анкета отправлена |
| Язык | на каком языке была открыта страница |
| Возраст | число полных лет (от 18) |
| Образование, Занятость, Семейное положение | выбранный вариант |
| Частота, Количество, Влияние на жизнь | баллы трёх вопросов ICIQ-SF |
| Сумма ICIQ-SF | от 0 до 21 |
| Степень | нет / лёгкая / умеренная / тяжёлая / очень тяжёлая |
| 7 столбцов ситуаций | 1, если ситуация отмечена, иначе 0 |

Имя, телефон, email и IP-адрес не собираются.

## Подключение (один раз, около 5 минут)

1. Откройте [sheets.new](https://sheets.new) под Google-аккаунтом, в котором должна храниться таблица (лучше аккаунт работодателя или проекта). Назовите таблицу, например «UroWoman — анкеты».
2. В меню выберите **Расширения → Apps Script**.
3. Удалите весь код в открывшемся редакторе и вставьте содержимое файла [`Code.gs`](Code.gs). Нажмите «Сохранить».
4. Вверху выберите функцию **setup** и нажмите **Выполнить**. Google попросит разрешение на доступ к этой таблице — разрешите. В таблице появится лист «Ответы» с заголовками.
5. Нажмите **Начать развертывание → Новое развертывание**. Тип — **Веб-приложение**. Укажите:
   - «Запуск от имени»: **От моего имени**;
   - «У кого есть доступ»: **Все**.
6. Нажмите **Начать развертывание** и скопируйте **URL веб-приложения** (он заканчивается на `/exec`).
7. Впишите этот адрес в `netlify.toml` в строку `SURVEY_ENDPOINT = "..."` и отправьте изменение через pull request. После слияния блок согласия появится на сайте.

Проверка: откройте адрес из шага 6 в браузере — должна появиться надпись `UroWoman survey endpoint is running.`

Если позже изменить код скрипта, нужно выбрать **Управление развертываниями → Изменить → Новая версия**, иначе будет работать старая версия.

## Как получить Excel

**Анкеты.** В таблице: **Файл → Скачать → Microsoft Excel (.xlsx)**. Работодателю можно дать доступ к таблице на просмотр, и он будет скачивать файл сам.

**Статистика сайта.** В GoatCounter: **Settings → Export → Start export**. Скачается файл CSV, он открывается в Excel. В нём просмотры по страницам, источники переходов, страны, устройства и событие `iciq-sf-completed-…` (сколько раз прошли тест).

## Важные ограничения

- **Этика.** Сбор исследовательских данных требует информированного согласия (оно есть на странице) и, как правило, одобрения локальной этической комиссии. Это нужно подтвердить у руководителя исследования до включения сбора.
- **Анонимность.** Отдельную запись нельзя найти и удалить по просьбе участницы, потому что неизвестно, чья она. Об этом сказано в политике конфиденциальности.
- **Достоверность.** Адрес приёма ответов виден в коде сайта, поэтому теоретически туда можно отправить выдуманные анкеты. Скрипт принимает только корректные значения, но при анализе стоит смотреть на подозрительные серии одинаковых ответов.
- **Превью веток.** С превью-адресов Netlify ответы не отправляются, чтобы тестовые анкеты не попадали в таблицу.
