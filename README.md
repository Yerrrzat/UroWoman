# UroWoman Kazakhstan

Информационный портал о недержании мочи у женщин. Статический сайт на трёх языках: русский (`/`), казахский (`/kk/`), английский (`/en/`).

## Структура

```
site/
  assets/        styles.css, script.js, favicon.svg
  pages/ru/      страницы на русском
  pages/kk/      страницы на казахском
  pages/en/      страницы на английском
build.py         сборка сайта в dist/
docs/            техническая документация и план развития (в сайт не попадает)
```

Каждая страница — это фрагмент HTML с заголовком-комментарием:

```html
<!--
title: Заголовок страницы
description: Описание для поисковиков
section: patient          (какой пункт меню подсвечивать; по умолчанию — имя файла)
main_class: container article-page
-->
...содержимое...
```

Шапка, меню, переключатель языка, подвал, canonical/hreflang, sitemap и поисковый индекс генерируются автоматически. Страница с одинаковым именем файла в `ru/`, `kk/` и `en/` считается переводом.

## Сборка

Нужен только Python 3.8+ (без зависимостей).

```bash
python build.py            # собрать в dist/
python build.py --serve    # собрать и открыть на http://localhost:8080
```

Сборка предупреждает о страницах без перевода и о незакрытых пометках `TODO`.

## Публикация

Загрузите содержимое папки `dist/` на любой статический хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages или обычный веб-хостинг).

Перед публикацией проверьте в `build.py`:

- `BASE_URL` — адрес сайта (сейчас `https://urowoman.kz`);
- `BASE_PATH` — `/` для собственного домена или `/UroWoman/`, если сайт открывается по адресу вида `username.github.io/UroWoman/`.
