Какие данные мы получаем

Через форму обратной связи пользователь может добровольно указать имя, адрес электронной почты и тему обращения. Медицинские сведения не следует отправлять через эту форму.

Для чего используются данные

Контактные данные предназначены только для ответа на обращение и не передаются третьим лицам без законного основания.

Локальные инструменты

Результат онлайн-теста и записи дневника хранятся локально в браузере пользователя через localStorage. Они не отправляются на сервер в текущей версии сайта.

Согласие и удаление

Отправляя форму, пользователь подтверждает согласие на обработку указанных контактных данных. Для удаления локальных записей используйте кнопку очистки дневника или настройки браузера.
